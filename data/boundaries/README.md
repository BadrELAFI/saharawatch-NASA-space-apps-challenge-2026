# Country boundary source

`countries.geojson` is Natural Earth's public-domain **1:110m Admin 0 countries** dataset, downloaded on 2026-11-14 from the [Natural Earth vector repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson).

[Dataset description](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/) · [Public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/)

The geometry is retained locally for reproducible masks and geographic context. The application uses `ADMIN` names, center-point inclusion, and cosine latitude weighting. It does not fractionally allocate boundary cells. Boundaries and disputed areas are descriptive and imply no endorsement.
